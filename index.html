Score Counter

Keep track of the game!

Score Counter is a simple way to keep score when you're playing games with friends, in class, or at home. Choose a color for each team, tap Add a Point whenever they score, and the counter will keep track for you.

Customize player names and colors in Settings, then set the number of points needed to win before the game begins.

When a team reaches the winning score, the game announces the winner. Use Reset to start a new round.
